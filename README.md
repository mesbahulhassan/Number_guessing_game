# Number Guessing Game

A beginner-friendly Python number guessing game where the player chooses a number range and the number of attempts they want.

## Features

- Custom lower and upper number range
- Custom number of guesses
- Random secret number generation
- Higher/lower hints
- Input validation
- Range validation
- Attempt tracking
- Win condition

## How It Works

1. The player chooses the lower and upper limits.
2. The program generates a random number within that range.
3. The player chooses how many attempts they want.
4. The player enters guesses.
5. The program tells the player whether to guess higher or lower.
6. The game ends when the player guesses correctly or runs out of attempts.

## Requirements

- Python 3.0 or later version
